# Retail Sales Analytics: Power Query · Power Pivot · DAX

## Business problem
A retailer with 45 stores needs one trusted view of revenue, profit, returns and promotions.

## Data
5 CSV tables (20,000 orders, 180 products, 2,500 customers, 45 stores). Practice dataset.

## What I built
- Power Query: typing, cleaning, derived columns, data-quality checks
- Power Pivot: star schema with 4 relationships
- DAX: 50 measures (time intelligence, Pareto/ABC, RFM, what-if)
- Interactive Excel dashboard with Month / Region / Category filters

## Key insights
1. Electronics drives about 88% of net revenue.
2. Returns erased about ₹60 lakh of profit.
3. CLEARANCE20 promo has the lowest margin.
